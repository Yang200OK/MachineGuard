# LSTM 模型训练与发布

## 正式训练的安排

MachineGuard 正式 LSTM 训练固定完成 200 轮，不使用 early stopping。配置采用两层 LSTM，隐藏维度 64，dropout 为 0.2，批量大小 64，初始学习率 0.001。训练会保存最佳权重所在轮次，但最佳轮次不等于实际训练总轮数，不能把保存最佳权重解释为提前停止训练。

## 训练与验证数据怎样划分

FD001 训练发动机按设备划分为 80 台训练设备和 20 台验证设备。常量特征筛选和标准化拟合使用训练划分；验证和测试数据应用已保存的预处理。不能把同一设备的相邻窗口随机混入训练与验证后宣称设备隔离，也不能用测试标签参与当前设备预测。

## 发布模型包含什么

部署包保留模型权重、预处理配置和发布清单。运行服务按发布版本加载 CPU 权重，并核对文件哈希与数据库发布登记。预测使用部署包中的窗口大小和特征配置，不能临时改用另一套标准化统计量。模型文件缺失、哈希不一致或未登记发布时，服务明确报告错误。

## 后台模型校验会重新训练吗

后台任务中的“校验已发布模型”检查文件哈希、CPU 权重加载、预处理配置和发布登记，不重新训练模型，也不生成新的设备预测。校验通过说明部署依据可读取且登记一致，不能单凭校验通过宣称模型适用于真实工厂或满足所有预测精度要求。
