# 传感器趋势阅读指南

## 趋势统计的范围

设备工作台按选定的起始周期和末端观测周期计算传感器趋势。区间来自同一台设备的连续原始观测，不能读取末端之后的数据。所选字段必须是有效、唯一的原始字段，不能把官方测试标签当成传感器输入。

## 均值、变化量与相对变化

均值是区间观测值的算术平均值。变化量等于末值减首值。相对变化等于变化量除以首值的绝对值；首值为零时分母为零，相对变化不可定义，接口返回空值和 zero_denominator 状态，不补成零。这些统计量描述观测变化，不是故障概率。

## 斜率如何解释

趋势斜率按原始观测周期计算最小二乘直线，表示每周期的线性变化。它不是按自然日计算的增减速度。只有一个观测点时无法计算斜率，返回空值。曲线末值高于首值标为升高，低于首值标为降低，相同标为不变；这些标签并未识别变化原因。

## 单位和现场结论

当前接口没有登记传感器字段的物理单位，显示为未知。不能根据字段名称或曲线形状补写温度、压力或振动单位。单凭趋势不能证明某个部件损坏，也不能直接给出报警阈值或维修步骤；现场结论需要经过适用资料和专业检查核对。
