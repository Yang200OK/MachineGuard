# 报告候选

## 输入

服务器冻结本人设备、末端周期、趋势起始周期和字段；资料核对须显式选择并具有原知识权限。

## 工作流程

固定顺序读取设备概况、计算趋势、生成可信预测，并按选择检索已发布资料。该流程由代码确定，不声称模型自主规划工具。

模型只排列已校验的证据编号、选择枚举中的待人工核对项。所有事实正文、数值、预测身份、固定引用和限制均由代码装配，不接受模型新增事实、数值、诊断、维修操作或页码。

## 输出

未审核报告候选随分析结果原子保存；可以查看固定证据和原文。没有最终报告、审批接口、工单或图谱执行；候选不表示已经审核。

## 边界

RUL 必须来自本人可信 prediction_id，单位为运行周期；风险等级不是故障概率。趋势不证明故障原因，未知单位不补写。资料不足如实列明缺口，接口、模型或校验失败则终止，不重试或生成替代候选。

最多八次工具和六次模型调用，取消、租约、身份和来源在执行及终态保存前再次检查。
